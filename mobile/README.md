# Mobile — Flutter (Android)

Aplikasi scanner & API client. Akan di-scaffold pada **Fase 4** dengan:

```bash
flutter create . --org id.autograding --platforms android
```

Spesifikasi lengkap: [`docs/07-mobile-spec.md`](../docs/07-mobile-spec.md)

**Isi folder ini (saat Fase 4):** login, daftar kelas/ujian, kamera + OpenCV pipeline (deteksi 4 fiducial marker → warp → crop), review hasil AI + manual override.
